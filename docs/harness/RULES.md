# Rules

  kh-harness's own rules registry — the one it asks every repository to
  keep. Each rule names the mechanism that holds it. The kit's doctrine
  lives in its tests, so almost every rule here is `enforced-by: test` with
  a pointer at the test file; the two that only a human can hold say so.
